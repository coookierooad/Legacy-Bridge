# Example prompts
These are illustrative prompts, not recorded successful runs.

- Operator: Find the customer archive screen and report visible fields without changing data.
- Learner: Learn the business rules needed to process a customer record; distinguish facts from hypotheses.
- Orchestrator: Transfer authorized synthetic records between two systems using GUI only; check duplicates and verify each write.
- Auditor: Compare both systems using GUI evidence only, report missing, duplicate and differing records without modifying data.
- Recovery: Resume the previously interrupted authorized task after checking live state; skip verified completed records.

For each prompt, verify that the host selects only necessary skills, respects scope and reports uncertainty.
