# Installation
Download or clone the repository. Each directory under skills contains a SKILL.md with name and description metadata. Install only the desired directories using your host's documented skill mechanism. If no skill mechanism exists, manually provide the relevant instructions. Optional AGENT.md is host-neutral guidance, not a runtime plugin. A GUI-capable host and appropriate permissions are required for actual interaction. No package manager installation or API key is supplied. Test read-only navigation before authorized writes. Cross-platform compatibility is not established.
