# Environment observations
Reported observations from macOS Safari/WebKit with AppleScript/System Events, not universal guarantees: coordinate clicks can miss keyboard focus; accessibility focus followed by paste and readback helped. Native clipboard paste worked for Chinese text where keystroke input and another clipboard path failed. Direct click on tab radio elements worked in one test; AXPress syntax failed with error -2741 in some contexts. Simple accessibility commands were more reliable than incompatible action syntax. High-DPI screenshots may require logical-coordinate conversion. Accessibility enumeration sometimes returned no elements; duplicate windows introduced ambiguity. Revalidate locally and use a different permitted mechanism when necessary. No raw logs are included.
